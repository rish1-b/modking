# ModKing — Mod Hosting Site (v1)

A minimal mod-upload/download/rating site. Built with Next.js + Supabase.

## Setup already done
- Supabase project created, schema run, mod-files bucket created

## Remaining steps
1. Copy `.env.local.example` values into Vercel's environment variables when deploying
2. Deploy via Vercel (Import from GitHub)
3. Optional: set up Discord OAuth in Supabase Authentication settings

## Next steps once live
- Add a UPI donation QR on the mod detail page
- Add Google AdSense once you have steady traffic
